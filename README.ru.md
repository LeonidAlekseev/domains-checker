Консольный инструмент на TypeScript/Deno для массовой проверки свободных доменов в `.ru` и любой зоне с RDAP. Генерирует
имена по маске и проверяет их: сначала быстро через DNS, затем оставшиеся через whois.ru или RDAP. Не нужны ни `dig`, ни
`curl`.

## Возможности

- 🎭 **Маски**: `gen CVCV` печатает все подходящие имена по одному в строке.
- 🔊 **`--nice`**: оставляет только имена, которые легко читать и произносить.
- ⚡ **Сначала DNS**: NS-запрос через `1.1.1.1`, 40 запросов параллельно, закрывает большинство имён.
- 🔎 **whois / RDAP для остальных**: `whois.ru` для `.ru`, RDAP (IANA bootstrap) для других зон находят
  зарегистрированные домены без NS-ответа.
- 🌍 **Любая зона**: `--tld ru,com,app`; кириллические имена и зоны (`рф`) работают.
- 🔁 **Повторы**: запрос к whois повторяется до 3 раз; имена, которые так и не проверились, помечаются `ERR`.
- 📦 **Один бинарник**: сборки для Linux, macOS и Windows.

## Установка

```sh
# Вариант 1: готовый бинарник со страницы релизов
#   https://github.com/LeonidAlekseev/domains-checker/releases
#   положите в PATH под именем domains-checker

# Вариант 2: из JSR (нужен Deno 2+)
deno install -g -n domains-checker --allow-net --allow-env=CONS,VOWS,WHOIS_P --allow-read=/dev/tty,CONIN$ \
  jsr:@leonidalekseev/domains-checker

# Вариант 3: из исходников (нужен Deno 2+)
git clone https://github.com/LeonidAlekseev/domains-checker
cd domains-checker
deno task compile                 # → dist/domains-checker
# или запуск без сборки:
deno task start --help
```

> [!NOTE]
> Deno по умолчанию не ставит версии, опубликованные меньше 24 часов назад. Если свежий релиз не ставится, добавьте к
> команде установки `--minimum-dependency-age=0`.

## Быстрый старт

```sh
echo "teef zvom" | domains-checker check
domains-checker gen CVCV --nice | domains-checker check > result.txt
grep ^FREE result.txt
```

## Использование

```sh
domains-checker gen MASK [--nice]   # напечатать имена по маске
domains-checker check [--tld ru,com]  # читать имена из stdin, печатать по строке результата на домен
domains-checker --help              # также: --version
```

### Маска

| Символ                     | Значение                              |
| -------------------------- | ------------------------------------- |
| `C`                        | согласная                             |
| `V`                        | гласная                               |
| `D`                        | цифра `0-9`                           |
| `L`                        | буква `a-z`                           |
| `A`                        | любой из `a-z`, `0-9`, `-`            |
| строчная буква, цифра, `-` | он сам (например, `shop` или `CVC-D`) |

Имена, недопустимые в `.ru`, пропускаются: короче 2 или длиннее 63 символов, `-` в начале или конце, `--` на позициях
3–4. Если маска даёт больше миллиона комбинаций, `gen` пишет предупреждение в stderr.

### `--nice`

Оставляет только произносимые имена. Каждая буквенная часть имени (цифры и `-` разделяют части) должна содержать
гласную, не содержать запрещённых букв (`q x w j c y` — поэтому `y` здесь не проходит, хотя в остальном считается
гласной) и удвоенных букв, иметь не больше двух согласных или двух гласных подряд и только распространённые сочетания
согласных вроде `st`, `br`, `nd`. Все правила — в `src/nice.ts`.

### Ввод `check`

Имена подаются в stdin через пробел, запятую или перевод строки. Принимаются буквы (в том числе кириллица), цифры и `-`;
регистр игнорируется, дубликаты отбрасываются. Имя без точки проверяется в каждой зоне из `--tld` (через запятую, по
умолчанию `ru`); имя с точкой (`teef.io`) — как есть. Запросы идут в punycode, в выводе остаётся то, что вы ввели.

### Формат вывода

| Строка                         | Значение                                               |
| ------------------------------ | ------------------------------------------------------ |
| `FREE name.tld`                | не зарегистрирован по данным реестра                   |
| `taken-delegated name.tld`     | занят, есть NS-записи                                  |
| `taken-whois name.tld (STATE)` | занят по whois.ru, показан `state:`                    |
| `taken-rdap name.tld`          | занят по RDAP                                          |
| `UNKNOWN name.tld`             | у зоны нет ни whois.ru, ни RDAP, пока проверить нельзя |
| `ERR name.tld`                 | ответа нет — перезапустите для этих имён               |

`FREE` значит «не зарегистрирован»: премиальные и зарезервированные имена всё равно могут быть недоступны. `FREE` не
печатается без ответа реестра. Строки отсортированы. Только свободные: `grep ^FREE result.txt`.

### Переменные окружения

| Переменная | По умолчанию      | Описание                                                                                                          |
| ---------- | ----------------- | ----------------------------------------------------------------------------------------------------------------- |
| `WHOIS_P`  | `2`               | параллельных запросов к whois. whois.ru показывает капчу после нескольких тысяч быстрых запросов — держите низким |
| `CONS`     | остальные 20 букв | согласные для `C`, через пробел                                                                                   |
| `VOWS`     | `a e i o u y`     | гласные для `V`, через пробел                                                                                     |

```sh
CONS="b d l m n r t v" VOWS="a o e i" domains-checker gen CVCVC | domains-checker check
```

## Как работает

1. **DNS**: NS-запрос для домена через `1.1.1.1`, по 40 одновременно. Пришёл NS-ответ — домен занят (`taken-delegated`).
2. **Реестр**: всё остальное — нет ответа, NXDOMAIN, нет NS-записей или ошибка DNS — идёт в реестр. `.ru` проверяется
   через `whois.ru`: страница сообщает, что домен свободен, либо показывает его `state:`. Зоны из IANA RDAP bootstrap
   (`data.iana.org/rdap/dns.json`, грузится один раз за запуск) — через RDAP: 200 — занят, 404 — свободен, 429 — ждём
   `Retry-After` и повторяем. Остальные зоны — `UNKNOWN`. Если bootstrap не загрузился, `check` завершается с ошибкой.

## Решение проблем

#### `captcha: whois.ru blocked ...`

whois.ru потребовал капчу. После этого новые запросы к whois.ru не начинаются; уже полученные результаты сохраняются.
Дальше:

1. Если остался ещё один `--proxy URL`, `check` переключается на него и продолжает. `--proxy` можно повторять, он
   действует только на whois.ru (DNS не проксируется) и берётся по одному на капчу; первые запросы идут напрямую. Схемы:
   `http://`, `https://`, `socks5://`, `socks5h://` (`socks4://` Deno не принимает)..
2. Иначе, при наличии терминала, в stderr печатается `https://whois.ru/<имя>.ru`. Пройдите капчу в браузере и нажмите
   Enter, чтобы продолжить, или `q` + Enter, чтобы остановиться. Запрос читает управляющий терминал (`/dev/tty`,
   `CONIN$` в Windows), поэтому работает и в `gen | check`. Если капча вернулась, вопрос повторяется.
3. Без терминала (cron, CI) программа останавливается с сообщением в stderr.

При остановке непроверенные имена помечаются `ERR`. Помогает не всегда: если whois.ru привязывает капчу к сессии
браузера, а не к IP, прохождение капчи в браузере или смена прокси могут ничего не дать. Тогда подождите, уменьшите
`WHOIS_P` и запустите снова.

#### `ERR name` в результатах

whois не дал внятного ответа за 3 попытки (таймаут, ошибка сети или капча). Скормите `ERR`-имена обратно:
`grep ^ERR result.txt | cut -d' ' -f2 | domains-checker check`.

#### `invalid mask …`

В маске допустимы только `C V D L A`, строчные буквы, цифры и `-`.

## FAQ

**Почему `y` — гласная?** По умолчанию `V` — это `a e i o u y`, а `C` — остальные 20 букв. Меняется через `VOWS` и
`CONS`.

**Проверяет ли другие зоны?** Да: `--tld ru,com,app`. Зоны без RDAP (например `.io`, `.me`) пока дают `UNKNOWN`.

**Почему DNS перед whois?** Он быстрый и без капчи. whois.ru медленнее и ограничен, поэтому ему достаются только имена,
которые DNS не решил.

## Разработка

```sh
deno task check     # fmt, lint, проверка типов
deno task test      # unit-тесты
deno task start     # запуск из исходников
deno task compile   # сборка dist/domains-checker
```

Структура:

```
src/main.ts    CLI: аргументы, справка, команды gen и check
src/gen.ts     раскрытие маски и правила имён .ru
src/nice.ts    эвристика --nice
src/check.ts   проверки DNS, whois и RDAP, разбор ответа
tests/         unit-тесты
```

Релиз: поднять `version` в `deno.json`, затем `git tag v<version> && git push origin v<version>`. CI соберёт бинарники
для Linux, macOS и Windows в GitHub Release и опубликует пакет в JSR.
