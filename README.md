# domains-checker

Массовая проверка свободных доменов `.ru` из консоли. Один бинарник на Deno, без `dig` и `curl`.

- `domains-checker gen MASK` — генерирует имена по маске (`C` — согласная, `V` — гласная, `D` — цифра, `L` — буква, `A`
  — любой из `a-z0-9-`; строчные буквы, цифры и `-` — литералы).
- `domains-checker check` — проверяет занятость: сначала быстро через DNS, затем оставшиеся через whois реестра.

## Установка

Нужен [Deno](https://deno.com). Запуск из клонированного репозитория: `deno task start gen CVCV`; сборка бинарника:
`deno task compile` (результат — `dist/domains-checker`).

## Использование

```sh
echo "teef zvom" | domains-checker check
domains-checker gen CVCV | domains-checker check > result.txt
CONS="b d l m n r t v" VOWS="a o e i" domains-checker gen CVCVC | domains-checker check
```

Имена подаются в stdin без `.ru`, через пробел, запятую или перевод строки.

### Формат вывода

| Строка                     | Значение                                       |
| -------------------------- | ---------------------------------------------- |
| `FREE name`                | домен свободен                                 |
| `taken-delegated name`     | занят, есть NS-записи                          |
| `taken-whois name (STATE)` | зарегистрирован, но не делегирован             |
| `ERR name`                 | whois не ответил — перезапустите для этих имён |

Только свободные: `grep ^FREE result.txt`.

## Как работает

1. **DNS**: запрос NS через `1.1.1.1`, 40 потоков. Есть NS — домен занят.
2. **whois**: оставшиеся имена проверяются через `whois.ru` — ловит зарегистрированные, но не делегированные домены.

## Настройки

| Переменная | По умолчанию         | Описание                                                                                          |
| ---------- | -------------------- | ------------------------------------------------------------------------------------------------- |
| `WHOIS_P`  | `2`                  | потоков whois. whois.ru показывает капчу после нескольких тысяч быстрых запросов — держите низким |
| `CONS`     | все 21 неглас. буква | согласные для `gen`                                                                               |
| `VOWS`     | `a o e`              | гласные для `gen`                                                                                 |

Если в stderr появилось `captcha: whois.ru blocked` — остановитесь и повторите позже.
